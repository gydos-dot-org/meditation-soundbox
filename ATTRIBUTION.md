- NAudio for Windows audio playback and WAV writing.
- Microsoft .NET SDK.
- Microsoft Visual C++ Redistributable, needed by Piper on Windows.
- Meta-V KJV Bible database with metadata from Theonize GitHub project.

Hardware/synth names such as 808, 909, Moog, MPC, Yamaha, Casio, 303, and Akai are used only as broad descriptive inspiration labels. No proprietary samples, ROMs, or exact emulations are included.
